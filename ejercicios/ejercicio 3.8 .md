## Ejercicio 3.8
# ¿Qué significa la prueba A/B? ¿Cómo se planea y qué aplicaciones tiene?

La prueba A/B es una técnica que permite comparar dos versiones de un producto, página web, anuncio o servicio para determinar cuál funciona mejor.

+ Versión A: es la versión original.
  
+ Versión B: es la versión modificada.
  
+ Planeación: se define un objetivo, se divide a los participantes en dos grupos, se muestra una versión a cada grupo y se comparan los resultados mediante métricas.

+ Aplicaciones: comercio electrónico, páginas web, publicidad, aplicaciones móviles y evaluación de promociones.

  Por ejemplo, una tienda en línea puede comparar dos diseños de una página para descubrir cuál consigue más compras.

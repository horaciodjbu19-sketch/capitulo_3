##Ejercicio 3.18
# ¿Cuál es la diferencia entre los datos de entrenamiento y los datos de prueba?

+ Datos de entrenamiento (training data): son los datos que se utilizan para enseñar al modelo de aprendizaje automático a identificar patrones y realizar predicciones.

+ Datos de prueba (test data): son datos separados que se utilizan para evaluar qué tan bien funciona el modelo con información que no utilizó durante el entrenamiento.

  # Ejemplo

  Si tenemos 1000 fotografías de perros y gatos, podemos utilizar 800 para entrenar el modelo y reservar 200 para probarlo.
  + 800 fotografías: datos de entrenamiento.

  + 200 fotografías: datos de prueba.

  La idea es comprobar si el modelo puede clasificar correctamente fotografías nuevas.
      
  Diferencia principal: los datos de entrenamiento sirven para aprender, mientras que los datos de prueba sirven para evaluar el desempeño del modelo.

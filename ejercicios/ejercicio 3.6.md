## Ejercicio 3.6

# Explica los términos datos “etiquetados” y “no etiquetados”.
# ¿Cómo puedes identificar si los datos están etiquetados o no?

+ Datos etiquetados (labeled data): son datos que incluyen una respuesta, categoría o resultado conocido. 
Por ejemplo, una tabla con la edad, el género y el estado de salud de cada persona.

+ Datos no etiquetados (unlabeled data): son datos que contienen características, pero no incluyen una respuesta o categoría objetivo. 
Por ejemplo, una tabla que solamente contiene la edad y el género de las personas.

Para identificarlos, se debe observar si los datos incluyen una columna que indique el resultado que se desea predecir.
Si existe esa columna con respuestas conocidas, los datos están etiquetados; si no existe, se consideran no etiquetados para esa tarea.

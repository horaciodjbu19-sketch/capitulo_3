## Ejercicio 3.3
# ¿Cuáles son las similitudes y diferencias entre el aprendizaje supervisado y el no supervisado?

+ # Tres diferencias:
1. El aprendizaje supervisado utiliza datos etiquetados, mientras que el no supervisado utiliza datos sin etiquetas.

2. El aprendizaje supervisado predice resultados conocidos, mientras que el no supervisado descubre patrones o grupos desconocidos.

3. El aprendizaje supervisado se utiliza para clasificación y regresión, mientras que el no supervisado se utiliza
   para agrupamiento y búsqueda de relaciones entre datos.

   + # Tres similitudes:
     
1. Ambos son tipos de aprendizaje automático (Machine Learning).
   
2. Ambos utilizan datos para entrenar modelos y encontrar patrones.
   
3. Ambos permiten analizar información y resolver problemas mediante algoritmos.
